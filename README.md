# Красивый хвостик

Готовый одностраничный сайт груминг-салона. Проект работает без сборщика и внешних зависимостей.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер в папке проекта:

```bash
python3 -m http.server 8080
```

После этого сайт будет доступен по адресу `http://localhost:8080`.

## Структура

- `index.html` — разметка сайта;
- `styles.css` — дизайн и адаптивные стили;
- `app.js` — интерактивный прайс, поиск, мобильное меню и галерея;
- `assets/` — логотип и реальные фотографии работ;
- `dist/` — готовая версия для размещения на хостинге.
